WattGuard 사용장치 안내

서비스: WattGuard 전력 이상 감지·관리
접속 주소: https://wattguard.suaveforge.com

1. 이용 장치
PC, 스마트폰, 태블릿의 최신 웹브라우저에서 이용합니다. 별도 앱 설치는 필수가 아닙니다. 웹/PWA로 시연할 수 있습니다.

2. 전력 데이터 연동
WattGuard는 고객 동의를 받은 한전 OPM 데이터를 서비스 승인 후 연동하는 방식으로 개발 중입니다. 계량기나 센서의 추가 설치는 기본 사용의 필수 조건으로 확정되어 있지 않습니다.

3. 사용 순서
웹 접속 → 전력 사용 추이 확인 → 이상 징후 확인 → 점검·조치 기록 → 조치 후 재확인

4. 현재 단계
웹/PWA 시제품이 구현되어 있습니다. 실제 한전 API 연동, 제공 지연, 탐지 성능은 실증 예정입니다.
